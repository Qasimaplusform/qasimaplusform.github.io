# داشبورد متابعة الاتفاقيات — قسيمة بلس

صفحة `tracker.html` لمتابعة اتفاقيات العملاء مع المناديب:

- **اتفاقية بتاريخ** → صالحة (تنتهي بعد ٣٠ يوم من تاريخها — قابل للتعديل).
- **اتفاقية بدون تاريخ** → منتهية / باقية، تحتاج إعادة إرسال.
- تقرير متابعة حسب كل مندوب (كم صالحة / كم قاربت على الانتهاء / كم للمتابعة).
- ملاحظة لكل عميل لتسجيل حالته أو المشكلة.
- إدخال البيانات بثلاث طرق: **لصق من Excel**، **رفع CSV**، أو **إضافة يدوية**.

الرابط بعد النشر: `https://qasimaplusform.github.io/tracker.html` (غير معلن — لا يظهر في الفورم الرئيسي).

## تفعيل المزامنة عبر Google (اختياري لكن مُوصى به)

بدون مزامنة، البيانات تُحفظ في متصفح جهازك فقط. للمزامنة ومشاركتها مع الفريق:

1. افتح **Google Sheets** جديد (سيكون قاعدة البيانات).
2. من القائمة: **Extensions → Apps Script**.
3. امسح أي كود موجود والصق محتوى ملف [`agreements.gs`](./agreements.gs) بالكامل.
4. احفظ، ثم **Deploy → New deployment → Web app**:
   - *Execute as:* **Me**
   - *Who has access:* **Anyone**
5. انسخ رابط الـ Web app المنتهي بـ `/exec`.
6. في `tracker.html` اضغط **⚙️ الإعدادات** → الصق الرابط → **حفظ**.

النقطة الملوّنة بجانب زر "مزامنة" في الأعلى:
🟢 متصل ومتزامن · 🟡 محلي (بدون مزامنة) · 🔴 تعذّر الاتصال.

> الرمز السري `SECRET` في `agreements.gs` يجب أن يطابق الموجود في `tracker.html`
> (الافتراضي: `qplus2026`). إذا غيّرت أحدهما غيّر الآخر.

## تنسيق اللصق / ملف CSV

ترتيب الأعمدة المتوقع (الأول والثاني إلزاميان):

| اسم العميل | المندوب | التاريخ | الجوال | ملاحظة |
|-----------|---------|---------|--------|--------|
| محل النخبة | أحمد بافيل | 2026-06-20 | 0501234567 | تم التوقيع |
| مؤسسة الريان | يوسف باسبيت | *(فارغ)* | 0559876543 | ينتظر موافقة المالك |

- اسم المندوب يُطابَق تلقائياً مع قائمة المناديب الـ٢٤ المعرّفة في النظام.
- صف **بتاريخ** = صالح · صف **بدون تاريخ** = منتهٍ ويحتاج إعادة إرسال.
- التواريخ المقبولة: `2026-06-25` أو `25/06/2026` أو `25-6-2026`.
